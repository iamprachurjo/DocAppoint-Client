# 🩺 Prescriptio - Doctor Appointment Booking Platform

**Prescriptio** is a modern, full-stack healthcare platform designed to seamlessly connect patients with trusted medical professionals. Doctors can manage their profiles via an admin portal, while patients can search for specialists, book convenient appointment slots, and manage or cancel their bookings effortlessly.

---

## ✨ Key Features

- ⚡ **Fast & Lightweight:** Optimized performance for lightning-fast page loads and smooth user interactions.
- 🔒 **Robust Authentication:** Secure user authentication powered by Better Auth & JWT (JSON Web Tokens).
- 📱 **Fully Responsive UI:** Seamlessly designed for desktop, tablet, and mobile devices using Tailwind CSS.
- 📅 **Easy Appointment Management:** Instant booking system with date/time slot selection and cancellation options.
- 👨‍⚕️ **Doctor & Admin Portal:** Doctors can manage their availability, specialty profiles, and patient bookings.
- 📈 **Scalable MVP:** Built on a modular architecture that easily scales from an MVP into an enterprise platform.

---

## 🛠️ Tech Stack

### **Frontend**
- ⚛️ **React.js** / 🔺 **Next.js** - UI Components & Framework
- 🎨 **Tailwind CSS** - Styling & Layouts

### **Backend**
- 🟢 **Node.js** - Runtime Environment
- 🚀 **Express.js** - RESTful API Server

### **Database & Auth**
- 🍃 **MongoDB** - Database
- 🔑 **Better Auth + JWT** - Secure Authentication & Authorization
